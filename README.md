# nanfetch
opfetch but no ai used  
syntax is nanfetch [logo] or nanfetch  
example:  
nanfetch arch  
nanfetch generatix  

if you wanna install this on your system run this from where nanfetch is:  
sudo mv nanfetch /usr/local/bin/nanfetch  
or if you use doas:  
doas mv nanfetch /usr/local/bin/nanfetch
